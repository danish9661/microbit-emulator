Load firmware, then run it

Drop a .hex / .bin built for flash 0x0 (ARM GCC, no SoftDevice). Staging loads nothing into the core; Run boots.

Presets run the same boot path as a dropped file: MBR vectors at 0x0, no UICR records. MicroPython continues straight into the direct-app boot at 0x1C000.
